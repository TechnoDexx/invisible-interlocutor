# Незримый собеседник

Цифровое пространство для диалога с ИИ.

Проект для тех, кому нужен внимательный слушатель.

## Возможности

- Диалог с ИИ
- Хранение истории
- Авторизация
- Экспорт и импорт истории
- Резервное копирование через Git

## Быстрый старт

Клонируйте репозиторий. Создайте виртуальное окружение. Установите зависимости. Запустите app.py.

## Структура веток

- main — стабильная
- work — рабочая
