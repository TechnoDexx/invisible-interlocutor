# Незримый собеседник (Invisible Interlocutor)

Веб-приложение для безопасного и приватного диалога с искусственным интеллектом. Проект создан как цифровое пространство для тех, кому важен внимательный, непредвзятый слушатель с возможностью полного контроля над своими данными.

## 🛠 Стек технологий
- **Backend:** Python 3.13, Flask
- **База данных:** YDB (Yandex Database)
- **Интеграции:** Yandex AI Studio (OpenAI-совместимый API)
- **Безопасность и Auth:** Flask-Login, Flask-WTF (CSRF protection)
- **Инфраструктура:** Docker, python-dotenv
- **Frontend:** HTML, CSS (Jinja2 templates)

## ✨ Ключевые возможности
- **Приватный диалог:** Взаимодействие с ИИ через настраиваемые промпты.
- **Управление данными:** Полный экспорт и импорт истории переписки (JSON).
- **Безопасность:** Защита от CSRF-атак, хеширование паролей, безопасное хранение сессий.
- **Надежность:** Таймауты запросов к ИИ, корректное управление соединениями с БД, резервное копирование через Git.
- **Уведомления:** Интеграция с SMTP (Flask-Mail) для восстановления доступа или уведомлений.

## 🏗 Архитектура проекта
Проект следует модульной структуре для удобства поддержки и масштабирования:
- `core/` — бизнес-логика (клиент ИИ, управление сессиями, работа с пользователями и историей в YDB).
- `services/` — внешние сервисы (например, `MailService` для отправки писем).
- `templates/` и `static/` — пользовательский интерфейс.
- `app.py` — точка входа и конфигурация приложения Flask.

## 🚀 Быстрый старт

### Вариант А: Через Docker (Рекомендуется)
1. Склонируйте репозиторий: `git clone <url>`
2. Создайте файл `.env` на основе `.env.example` и заполните его своими ключами.
3. Соберите и запустите контейнер:
   ```bash
   docker build -t invisible-interlocutor .
   docker run -p 8080:8080 --env-file .env invisible-interlocutor
   ```
4. Откройте в браузере: `http://localhost:8080`

### Вариант Б: Локальный запуск
1. Создайте виртуальное окружение: `python3 -m venv venv`
2. Активируйте его: `source venv/bin/activate` (или `venv\Scripts\activate` на Windows)
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите приложение: `python app.py`

## 🔒 Безопасность
- Все чувствительные данные вынесены в переменные окружения (`.env`).
- В продакшене настоятельно рекомендуется сгенерировать уникальный `SECRET_KEY` и отключить `DEBUG` режим.
